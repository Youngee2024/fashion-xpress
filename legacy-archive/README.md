# Legacy FashionXpress prototype

This directory preserves the pre-React HTML, CSS, JavaScript, image, and model assets for reference.

These files are not part of the active Vite application. Keeping the legacy HTML below this directory prevents files such as `about.html` and `collections.html` from intercepting React Router paths at the project root.

The active application lives in `src/`, uses assets from `public/`, and is entered through the root `index.html`.
